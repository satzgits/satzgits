### Hey, I'm Savith 👋

I'm a Computational Math student at Mahindra University. I build things with code — satellite detection models, quantum simulations, LLM pipelines, and quant trading tools. I learn by building.

---

#### What I've Been Working On

**Quantum Computing** — I explored gate-based quantum simulation with CUDA.jl (GPU-accelerated Clifford circuits), contributed to QuantumClifford.jl and qutip-qip, and built my own GPU-accelerated quantum simulation framework. Most of this was in Julia and Python.

**LLMs & AI Agents** — I've built an LLM inference API (FastAPI + Docker), fine-tuned models with LoRA, built a RAG-based Q&A system, dabbled with AI agent evaluation pipelines, and forked potpie-ai (an AI agent platform) to understand agent architectures.

**Quantitative Finance**  — I'm building an event-driven backtesting engine, a Monte Carlo options pricer with Black-Scholes validation, a market data pipeline with live indicators, a portfolio optimization suite (mean-variance, Kelly, risk parity), and a C++ order book with price-time priority matching. It's a lot, but it's all the same math.

**Audio & Signal Processing** — I worked on lightweight audio source separation, edge-AI speech enhancement, and real-time voice activity detection. These were my first attempts at deploying ML to resource-constrained environments.

**MLOps & Infrastructure** — I built a model monitoring dashboard with data drift detection, experiment tracking with MLflow, and deployment pipelines with Docker + FastAPI.

**Graph Neural Networks** — Forked GraphNeuralNetworks.jl to learn graph-based learning. Not my strongest area, but I understand the fundamentals.

#### Things I Actually Know

**Languages**: Python, C++, Julia, CUDA  
**ML/DL**: PyTorch, YOLO, segmentation-models, HuggingFace, ONNX  
**Infra**: FastAPI, Docker, MLflow, Git  
**Domains**: Computer Vision, NLP, Quantum Simulation, Quant Finance  
**Currently learning**: C++ for low-latency systems, stochastic calculus, options pricing

#### Why I Build All This

I don't specialize in one thing because I'm still figuring out what I want to do long-term. But the thread connecting everything is: I like taking complex mathematical ideas and turning them into working code. Whether it's simulating a quantum circuit, pricing an option with Monte Carlo, or detecting vehicles in a satellite image — if it has math and code, I'm interested.
